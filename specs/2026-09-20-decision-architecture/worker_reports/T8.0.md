## Notes for Reviewers

- `SessionBinding.backend` was widened to include `'typesafe'` so the cross-provider reuse guard (`getProviderSession`) keeps compiling after `AgentBackend` widens. The session model itself is backend-agnostic — only the literal union changes.
- The `typesafe` descriptor is registered but no `runStage` path branches on it yet. Phase B / T8.1 / T8.2 land the HTTP adapter; for now `runStage` will report `backend 'typesafe' is not implemented in this slice` (same shape as `codex-cli` and `pi-cli`), which is the documented behaviour for unimplemented backends.
- `FACTORY_TYPESAFE_OFF` is a forwarder-only toggle — Phase B's `runtime/typesafe-backend.mjs` is the consumer. The dispatcher just guarantees the env var reaches the worker when set.
