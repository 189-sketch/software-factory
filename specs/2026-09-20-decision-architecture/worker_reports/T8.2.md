## Deliverable

`src/core/judgment-state.ts` exports:

- `interface JudgmentState` — verbatim copy of requirements.md §"State Shape Contract", including the `ReadonlyArray<{ ... isFactoryComment: boolean; ... }>` comment shape.
- `interface ReceiptRegistry` — opaque stub (`{ readonly [key: string]: unknown }`). The real registry lives in `src/agents/verify-behavior.ts`; defining the stub here keeps `src/core/` independent of `src/agents/`.
- `interface DecisionRecord` — minimum `{ action: string; outcome: string; ts: string }`.
- `interface JudgmentFactoryContext`, `interface JudgmentRepoSignals`, `interface JudgmentRoadmapSection`, `interface JudgmentIssueInput`, `interface BuildJudgmentStateOptions` — the input / output bags that keep the helper purely additive.
- `function buildJudgmentState(issue, ctx?, opts?)` — maps an existing `Issue` into the judgment-state `issue` shape (defaulting `updatedAt` from `createdAt`, classifying each comment with `isFactoryComment` from `core/factory-comments.ts`), populates factory context defaults (`failureCounts: {}`, `priorDecisions: []`), and only writes optional top-level fields (`roadmap`, `prDiff`, `specBody`, `implementationDiff`) when the caller supplies them.
- `function stateHashFor(state)` — implements the spec's SHA-256 formula: `sha256(updatedAt | '|' | comments.length | '|' | lastReceiptSha | '|' | lastTriageAt | '|' | labels.join(','))`, where `lastReceiptSha` is `sha256(JSON.stringify(lastReceiptRegistry))` when present or `''` when absent.

`src/__tests__/judgment-state.test.ts` covers:

1. `buildJudgmentState` populates issue fields from a minimal fixture (incl. factory-comment detection).
2. `updatedAt` fallback chain: `opts.issueUpdatedAt > issue.updatedAt > issue.createdAt`.
3. Factory context is honoured via `ctx` or `opts`; defaults (`{}` / `[]`) match the contract.
4. Default `repoSignals` are safe placeholders.
5. Optional top-level fields default to `undefined` and only populate when supplied.
6. Roadmap section is shallow-cloned so callers cannot mutate the input.
7. Custom `isFactoryComment` detector override works.
8. `stateHashFor` is deterministic and produces a 64-char lowercase sha-256 hex digest.
9. `stateHashFor` is sensitive to every input field (`updatedAt`, `comments.length`, `labels`, `lastTriageAt`, `lastReceiptRegistry`).
10. `stateHashFor` ignores the receipt slot when no registry is supplied (matching the spec's "absence encoded as ''" rule).
11. `stateHashFor` is intentionally oblivious to optional non-hash fields (`roadmap`, `prDiff`, `specBody`, `implementationDiff`).
